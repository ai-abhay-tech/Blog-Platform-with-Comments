# Blog Platform with Comments

A full-stack blogging platform with authentication, CRUD operations, comments system, REST APIs, and MySQL database integration.

## Features

- User Authentication
- Create/Edit/Delete Posts
- Comments System
- JWT Authentication
- Responsive UI
- MySQL Database

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Installation

1. Clone repository

2. Import `blog_platform.sql` into MySQL

3. Install dependencies

```bash
npm install
